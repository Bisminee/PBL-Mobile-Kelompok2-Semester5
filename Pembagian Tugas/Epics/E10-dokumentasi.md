# E10 — Dokumentasi

**Status:** 🟡 Sebagian

## 1. Apa yang harus dilakukan
- Menulis **logbook mingguan** dan notulen rapat.
- Mengumpulkan **150 foto lapangan** untuk bahan pengujian model.
- Mengumpulkan dan **menabulasi data kuesioner** usability.
- Menyusun **laporan milestone** dan **laporan akhir**.
- Menulis **dokumentasi fitur** dan merawat README repositori.
- Menjaga dokumentasi tetap **selaras** dengan kondisi aplikasi terkini.

## 2. Bagaimana melakukannya
- Tetapkan jadwal tetap: catat logbook **setiap minggu**, jangan menumpuk.
- Susun template sederhana untuk logbook (tanggal, kegiatan, kendala, rencana).
- Kumpulkan foto lapangan dari berbagai kondisi (dalam/luar ruangan, cahaya
  terang/gelap, latar berbeda) agar pengujian model realistis.
- Olah kuesioner menjadi tabel ringkas: jumlah responden, skor SUS, penilaian
  kecocokan rekomendasi.
- Susun laporan mengikuti **format resmi** dan urutan milestone.
- Setiap fitur selesai → tulis dokumentasinya di folder dokumentasi fitur.

## 3. Target yang harus dicapai
- **Logbook lengkap** dari Minggu 1 sampai Minggu 10.
- **150 foto lapangan** siap dipakai untuk pengujian ketahanan model.
- Data kuesioner **tertabulasi** dan siap dimasukkan ke laporan.
- **Laporan akhir lengkap** dikumpulkan sesuai jadwal.
- Dokumentasi fitur **mutakhir** dan dapat dipahami anggota tim baru.
- Seluruh klaim di laporan **didukung bukti** (metrik, tangkapan layar, data).

## 4. Ketergantungan
- **E4.1** (untuk konteks dataset), **E9** (hasil pengujian), **E8** (fitur).
- Sebagian dapat dimulai sejak Minggu 1 (logbook, foto lapangan).
