# Sera-Z — Deskripsi Epic

Satu dokumen per epic (E1–E10). Setiap dokumen berisi:
1. **Apa yang harus dilakukan** — daftar pekerjaan (tanpa detail kode).
2. **Bagaimana melakukannya** — pendekatan & langkah kerja.
3. **Target yang harus dicapai** — tujuan umum dan kriteria keberhasilan.
4. **Ketergantungan** dan **referensi**.

Tidak ada pembagian per orang — semua tugas terbuka untuk siapa saja
(lihat `../pembagian-tugas.md`).
